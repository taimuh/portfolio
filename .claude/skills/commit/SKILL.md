以下の手順でgitコミットを実施してください。

## 現在の状態を確認

```!
git status
git diff --staged
git diff
git log --oneline -5
```

## 手順

1. **変更内容を分析する**
   - ステージ済みの変更と未ステージの変更を確認する
   - ステージされていない変更は `git add` でステージしてからコミットするか、ユーザーに確認する
   - `.env` や認証情報などのセンシティブなファイルが含まれていないか確認する

2. **コミットメッセージを作成する**
   - **日本語**で記述する
   - 変更の「何を」ではなく「なぜ」に着目する
   - 過去のコミット履歴のスタイルに合わせる（例: `〇〇を修正しました。`、`〇〇をアップデート`）
   - 1行で簡潔にまとめる

3. **コミットを実行する**
   - HEREDOCを使用してメッセージを渡す
   - 末尾に必ず以下のCo-Authored-By行を追加する

```
git commit -m "$(cat <<'EOF'
コミットメッセージ

Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com>
EOF
)"
```

4. **完了を確認する**
   - `git status` でコミットが正常に完了したことを確認する

## 注意事項

- `--no-verify` や `--amend` は使用しない（ユーザーから明示的に求められた場合を除く）
- `git add -A` や `git add .` は避け、ファイルを個別に指定する
- リモートへのプッシュはユーザーから明示的に求められた場合のみ行う
